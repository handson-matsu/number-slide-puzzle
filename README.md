# SLIDE LAB

スライドパズルで転倒数と不変量を観察する、日本語の数学教育用Webアプリです。

## 起動

ビルド・インストールは不要です。リポジトリのルートで静的サーバーを起動します。

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開きます。ES Modules を使用するため、HTMLファイルを直接開くのではなくHTTPで配信してください。

## GitHub Pages

GitHub Pagesの公開設定は `main` ブランチの `/ (root)` を使用します。リポジトリ直下の `index.html` が配信され、`https://handson-matsu.github.io/number-slide-puzzle/` でアプリを利用できます。依存パッケージ・外部API・データベース・外部フォントは不要です。

## 操作

- 3×3・4×4・5×5を切り替え、空白に隣接するタイルをクリック／タップして移動します。矢印キーでは空白がその方向へ移動します。
- 「シャッフル」は完成形から合法手をサイズの2乗×80回実行します。直前の手の即時取り消しを避け、必ず解ける未完成の盤面を作ります。
- 「最初から」は現在の問題の開始盤面へ戻し、手数と履歴をリセットします。
- 「チャレンジ」は完成形の最後の数字タイル2枚を交換した問題です。サイズ変更時もモードを維持し、「シャッフル」で通常モードに戻ります。
- 「数理を見る」をONにすると、空白をn²として含む置換・転倒数・空白座標・不変量・ゴール比較を表示します。直前の手との比較と最近12状態の履歴で変化を観察できます。
- 履歴は数理表示OFFの間も記録し、問題変更・リスタートでリセットします。ページ再読み込み時は新しい問題になります。

## 数学とテスト

転倒数は空白も含むすべてのペアで計算します。1回の合法手で置換の偶奇と空白座標の和の偶奇が両方反転するため、`P = (I + r + c) mod 2` は不変です。ゴールでは常にP=0、チャレンジではP=1です。

Node.js 18以降で実行できます。

```sh
node --test logic.test.mjs
```

3サイズそれぞれについて通常・チャレンジ各10,000手の不変性、100回のシャッフル、ゴールとの差、境界での移動を検証します。

クリア表示のブラウザー回帰テストは、サーバー起動後に `http://localhost:8000/tests/clear.html` を開くと実行されます。テスト内だけで開始盤面を完成1手前に差し替え、実際のアプリを使って全3サイズ・数理ON/OFFの6ケースで、完成表示、手数、再完成、「もう一度」「シャッフル」を検証します。通常のアプリのシャッフルには影響しません。
